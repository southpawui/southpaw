Southpaw UI aims for GOV.UK-level rigour with shadcn's ergonomics, on [Base UI](https://base-ui.com).

- **You own the code.** Components install into your project with the shadcn CLI, so you can read and change them.
- **Accessible by default.** Every component is checked with axe, tested with the keyboard, and documented with its known issues.
- **Themeable.** Light, dark and high-contrast themes, plus three density modes, all from `--sp-*` CSS variables.

Use the **Theme** and **Density** controls in the sidebar to see every page and example in each mode.

## Every component page has the same sections

1. What it is, with a live example
2. When to use, when not to, and alternatives
3. Anatomy: the parts and their `data-slot` names
4. Variants and sizes
5. States
6. Content guidance
7. Accessibility: keyboard, focus, ARIA, the screen readers tested, and known issues
8. API reference

Each page also shows a status (alpha, beta, stable or deprecated), and is available as Markdown for LLMs at the same URL plus `.md`, or all together at [`/llms-full.txt`](/llms-full.txt).
